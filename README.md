# 🖼️ 圖片/照片 AI 畫質修復工具 (Real-ESRGAN GUI)

一款專為 Windows 設計的輕量、免繁雜配置的**本機 AI 圖片超解析度修復與放大工具**。  
基於 **Real-ESRGAN** 深度學習神經網路與 ncnn Vulkan 加速引擎，可將模糊、低解析度或老舊照片無損放大 **2x / 4x**，精準重建髮絲、膚質與材質紋理。

## ✨ 核心特色

1. **🚀 深度學習神經網路重建**：
   - `realesrgan-x4plus`：針對真實人像、風景與日常照片的通用超解析度修復。
   - `realesrgan-x4plus-anime`：動漫、插畫與二次元線條特化修復，保持邊緣平滑銳利。
   - `realesr-animevideov3`：高速模式，兼顧速度與品質。
2. **⚡ 免配 Python 深度學習環境**：
   - 無需安裝數 GB 的 PyTorch、CUDA 或繁複環境變數，基於 ncnn Vulkan 輕量執行檔即可流暢運行。
3. **📂 批次多圖與即時狀態監控**：
   - 支援多圖選取循序處理，歷程記錄框即時顯示單圖進度與時間戳記。
4. **⏹️ 毫秒級中斷與安全清理**：
   - 放大到一半可隨時中止，立即釋放 GPU 資源，並自動清除未完成之中繼檔案。
5. **📷 原生圖示啟動器 (零黑視窗 / 全自動適配路徑)**：
   - 附帶原生編譯的 Windows 啟動器（`圖片畫質提高工具.exe`），內嵌專屬相機鏡頭圖示（`assets/app.ico`）。
   - **完全無命令列黑視窗閃爍**，直接以背景無縫喚醒圖形介面。
   - **100% 可攜式**：採用動態相對路徑解析，無論使用者下載到何種資料夾路徑或磁碟槽（C/D/桌面），皆能立即點擊運行（徹底解決 Windows `.lnk` 捷徑因絕對路徑失效的問題）。
   - 若系統尚未檢測到 Python 環境，將主動彈出友善的引導安裝視窗。
6. **🧼 智慧塗抹消除浮水印 (4 重平移導航系統 / 局部放大精細塗抹)**：
   - 內建互動式修復畫布，支援滑鼠自由塗抹欲消除的文字、LOGO 或浮水印瑕疵。
   - **✋ 雙模式工具切換**：工具列提供 `[ ✏️ 塗抹模式 ]` 與 `[ ✋ 移動畫布 ]` 一鍵切換。切換為「移動畫布」後，**滑鼠左鍵即可直接拖動畫布平移**，筆電觸控板也能流暢操作！
   - **⌨️ 空白鍵 (Space) 專業抓手快捷鍵**：比照 Photoshop / Figma 操作習慣，塗抹中**按住空白鍵不放**，游標自動切換為抓手，此時**滑鼠左鍵拖曳即可平移視角**；放開空白鍵立即切回塗抹！
   - **🖱️ 全向滑鼠平移支援**：在任何模式下，**按住滑鼠右鍵或滾輪中鍵**拖曳皆可平移。
   - **🕹️ 鍵盤方向鍵微調**：支援鍵盤 `↑` `↓` `←` `→` 鍵每次微調移動 40px。
   - **🔍 視角無級縮放 (20% ~ 800%)**：支援滑鼠滾輪或按鈕自由縮放，解除邊界鎖定，細小角落字樣也能精準修補！
   - 支援 OpenCV 電影級 Telea 與 Navier-Stokes 影像修補演算法，並提供純 Pillow 邊緣羽化融合兜底。
   - 支援自訂筆刷粗細 (5~80px)、歷史復原 (Undo) 與清除標記。
   - 消除完成後支援**一鍵傳送至「AI 畫質放大」**，無縫銜接 4x 超解析度重建！
7. **🎬 影片去浮水印 (FFmpeg delogo) 邊界防禦演算法**：
   - 針對調用 FFmpeg `delogo` 濾鏡消除影片浮水印時，內建安全邊界鉗位保護機制。
   - 徹底杜絕因塗抹框選碰觸邊界（`x=0` 或 `y=0`）導致 FFmpeg 拋出 exit code `4294967274` (`-22 EINVAL: Logo area is outside of the frame`) 的崩潰問題。
8. **🛡️ 三段式降級兜底保障**：
   - 若未啟用 AI 引擎，自動降級為 Pillow 高品質 Lanczos 2x 插值 + UnsharpMask 銳化濾鏡；皆無時自動調用 ffmpeg。

## 🚀 快速上手

### 1. 一鍵啟動 (推薦)
下載專案或解壓縮後，在根目錄直接雙擊：
👉 **`啟動工具(免黑框).vbs`**（🌟 強烈推薦：原生無黑視窗靜音啟動，雙擊立即喚醒軟體介面）  
或使用 👉 **`啟動工具.bat`**（標準批次檔啟動入口，若遇環境問題可檢視終端機記錄）

### 2. 使用步驟
1. 點擊 **「➕ 選擇圖片」**，選取一張或多張圖片（支援 `.jpg`、`.png`、`.webp` 等格式）。
2. 在 **「修復參數設定」** 選擇適用的 AI 模型與放大倍率（2x 或 4x）。
3. 點擊 **「🚀 開始 AI 畫質修復」**，進度條將即時顯示各圖片處理進度，歷程記錄框將逐行輸出時間日誌。
4. 修復完成後，點擊 **「📁 開啟所在資料夾」** 即可檢視新產生的高畫質圖片（檔名後綴自動帶有 `_enhanced`）。

## 💡 技術常見問題與避坑備忘 (FAQ)

### Q1: 消除影片浮水印時 FFmpeg 拋出 exit code 4294967274 (-22 EINVAL) 報錯？
- **原因**：FFmpeg 的 `delogo` 濾鏡需要選區外圍周邊像素（預設 `band=1`）進行插值補全，強制要求 $x \ge band$ 且 $y \ge band$。若使用者塗抹至畫面最左側 ($x=0$) 或最頂部 ($y=0$)，FFmpeg 會因抓不到參考邊界而判定 `Logo area is outside of the frame` 並終止執行。
- **解決方案**：在組裝 FFmpeg 參數前加入安全邊界鉗位保護：
  ```python
  band = 1
  x = max(band, int(x))
  y = max(band, int(y))
  if x + w + band > video_w:
      w = max(1, video_w - band - x)
  if y + h + band > video_h:
      h = max(1, video_h - band - y)
  delogo_filter = f"delogo=x={x}:y={y}:w={w}:h={h}:band={band}"
  ```

### Q2: 塗抹浮水印時，放大後如何快速平移畫布？
- **最推薦操作**：**按住鍵盤空白鍵 (Space)**，游標即刻變為抓手，此時滑鼠左鍵可任意拖曳平移；放開即恢復塗抹。
- **亦可切換模式**：點擊工具列上的 `[ ✋ 移動畫布 ]`，滑鼠左鍵點擊直接拖曳，適合筆記型電腦觸控板使用。
- **全向滑鼠**：任何模式下按住滑鼠右鍵或滾輪中鍵皆可直接拖曳平移。
