# 🖼️ 圖片/照片 AI 畫質修復工具 (Real-ESRGAN GUI)

一款專為 Windows 設計的輕量、免繁雜配置的**本機 AI 圖片超解析度修復與放大工具**。  
基於 **Real-ESRGAN** 深度學習神經網路與 ncnn Vulkan 加速引擎，可將模糊、低解析度或老舊照片無損放大 **2x / 4x**，精準重建髮絲、膚質與材質紋理。

## ✨ 核心特色

1. **🚀 深度學習神經網路重建**：
   - `realesrgan-x4plus`：針對真實人像、風景與日常照片的通用超解析度修復。
   - `realesrgan-x4plus-anime`：動漫、插畫與二次元線條特化修復，保持邊緣平滑銳利。
   - `realesr-animevideov3`：高速模式，兼顧速度與品質。
2. **⚡ 免配 Python 深度學習環境**：
   - 無需安裝數 GB 的 PyTorch、CUDA 或繁複環境變數，基於 ncnn Vulkan 輕量執行檔即可流暢運行。
3. **📂 批次多圖與即時狀態監控**：
   - 支援多圖選取循序處理，歷程記錄框即時顯示單圖進度與時間戳記。
4. **⏹️ 毫秒級中斷與安全清理**：
   - 放大到一半可隨時中止，立即釋放 GPU 資源，並自動清除未完成之中繼檔案。
5. **📷 原生圖示啟動器 (零黑視窗 / 全自動適配路徑)**：
   - 附帶原生編譯的 Windows 啟動器（`圖片畫質提高工具.exe`），內嵌專屬相機鏡頭圖示（`assets/app.ico`）。
   - **完全無命令列黑視窗閃爍**，直接以背景無縫喚醒圖形介面。
   - **100% 可攜式**：採用動態相對路徑解析，無論使用者下載到何種資料夾路徑或磁碟槽（C/D/桌面），皆能立即點擊運行（徹底解決 Windows `.lnk` 捷徑因絕對路徑失效的問題）。
   - 若系統尚未檢測到 Python 環境，將主動彈出友善的引導安裝視窗。
6. **🧼 智慧塗抹消除浮水印 (Inpainting 局部放大精細塗抹)**：
   - 內建互動式修復畫布，支援滑鼠自由塗抹欲消除的文字、LOGO 或浮水印瑕疵。
   - **🔍 視角無級縮放與平移**：支援**滑鼠滾輪局部放大 (最高 800%)**、**按住右鍵拖曳平移 (Pan)**，搭配**雙色筆刷游標環**，角落細小字樣也能精準修補！
   - 支援 OpenCV 電影級 Telea 與 Navier-Stokes 影像修補演算法，並提供純 Pillow 邊緣羽化融合兜底。
   - 支援自訂筆刷粗細 (5~80px)、歷史復原 (Undo) 與清除標記。
   - 消除完成後支援**一鍵傳送至「AI 畫質放大」**，無縫銜接 4x 超解析度重建！
7. **🛡️ 三段式降級兜底保障**：
   - 若未啟用 AI 引擎，自動降級為 Pillow 高品質 Lanczos 2x 插值 + UnsharpMask 銳化濾鏡；皆無時自動調用 ffmpeg。

## 🚀 快速上手

### 1. 一鍵啟動 (推薦)
下載專案或解壓縮後，在根目錄直接雙擊：
👉 **`圖片畫質提高工具.exe`**（🌟 推薦：自帶相機鏡頭圖示，無黑視窗閃爍，自動偵測環境）  
或使用 👉 **`run_enhance.bat`**（純批次檔備用入口）

### 2. 使用步驟
1. 點擊 **「➕ 選擇圖片」**，選取一張或多張圖片（支援 `.jpg`、`.png`、`.webp` 等格式）。
2. 在 **「修復參數設定」** 選擇適用的 AI 模型與放大倍率（2x 或 4x）。
3. 點擊 **「🚀 開始 AI 畫質修復」**，進度條將即時顯示各圖片處理進度，歷程記錄框將逐行輸出時間日誌。
4. 修復完成後，點擊 **「📁 開啟所在資料夾」** 即可檢視新產生的高畫質圖片（檔名後綴自動帶有 `_enhanced`）。

## 💻 命令列模式 (CLI)

除了圖形視窗外，亦支援直接於終端機傳參或拖曳圖片處理：

```bash
# 單張或多張圖片批次修復
python enhance_image.py "C:\path\to\photo1.jpg" "C:\path\to\photo2.png"
```
